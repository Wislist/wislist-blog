# Butterfly 主题美化设计文档

## 项目概述

为基于 Hexo + Butterfly 主题的个人技术博客进行全面美化升级，采用简约现代的设计风格，增强用户体验和功能性。

## 设计目标

1. **视觉升级**：实现简约现代的设计风格，提升整体美观度
2. **功能增强**：添加深色模式、本地搜索、文章目录优化等核心功能
3. **性能优化**：实现图片懒加载和流畅的页面动画效果
4. **易于维护**：不修改主题源码，所有自定义内容通过配置和注入实现

## 整体架构

### 架构层次

```
配置层 (_config.butterfly.yml)
    ↓
自定义样式层 (source/css/custom.css)
    ↓
自定义脚本层 (source/js/custom.js)
    ↓
插件层 (hexo-generator-search)
    ↓
Butterfly 主题核心 (不修改)
```

### 设计原则

- **非侵入式**：不修改主题源码，通过配置和注入实现所有自定义
- **可维护性**：所有自定义内容集中管理，易于更新和回滚
- **性能优先**：优化加载速度，使用懒加载和缓存策略
- **渐进增强**：基础功能优先，高级功能可选

## 视觉设计系统

### 配色方案

**浅色模式**：
- 主色：`#2c3e50` - 深蓝灰，用于标题和重要文本
- 背景：`#ffffff` - 纯白
- 次级背景：`#f8f9fa` - 浅灰，用于卡片和区块
- 强调色：`#3498db` - 清爽的蓝色，用于链接和按钮
- 边框：`#e1e4e8` - 淡灰色

**深色模式**：
- 主色：`#e4e6eb` - 浅灰白，用于文本
- 背景：`#1a1a1a` - 深黑
- 次级背景：`#242424` - 稍浅的黑，用于卡片
- 强调色：`#5dade2` - 柔和的蓝色
- 边框：`#333333` - 深灰

### 字体排版

- 标题：系统默认无衬线字体栈
- 正文：行高 1.8，字号 16px
- 代码：JetBrains Mono, Fira Code, Consolas

### 动画效果

- 页面加载：淡入效果 300ms
- 卡片悬停：上浮 + 阴影 200ms
- 按钮交互：缩放效果 150ms
- 深色模式切换：平滑过渡 400ms
